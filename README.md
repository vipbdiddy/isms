# Ism's

Keep the sayings and stories of the people you've lost, and find the right one when you need it.

- **Website** (home page, privacy policy, terms): the Markdown files in this folder, published at https://vipbdiddy.github.io/isms/
- **The app**: [`app/`](app/), an Expo / React Native app. See [`app/README.md`](app/README.md).
- **Android download**: every change to `app/` on `main` builds a new APK at https://github.com/vipbdiddy/isms/releases/latest/download/isms.apk
- **Web version** (for iPhones and computers): every change on `main` publishes it at https://vipbdiddy.github.io/isms/app/, together with the website ([`.github/workflows/website.yml`](.github/workflows/website.yml); Settings → Pages → Source must be "GitHub Actions").
